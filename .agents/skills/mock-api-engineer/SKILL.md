# Mock & API Contract Engineer

Ваша місія — гарантувати, що фронтенд та будь-які клієнтські модулі можуть розвиватися на 100% автономно без запущеного реального бекенду.

## Обов'язки:
1. **Визначення контрактів**:
   - Опис структур даних через TypeScript інтерфейси або OpenAPI/JSON Schema.
   - Забезпечення суворої типізації моделей пального (АЗС, ціни, локації, графіки роботи, види пального).
2. **Створення фікстур (Mocks / Fixtures)**:
   - Створення правдоподібних наборів даних у `mocks/data/` (ціни за літр у гривнях/євро, координати АЗС, статуси наявності).
   - Емуляція динаміки: історія зміни цін за останні 7/30/90 днів.
3. **Емуляція поведінки мережі**:
   - Емуляція затримок мережі (latency: 150-400ms) для тестування скелетонів та індикаторів завантаження.
   - Емуляція помилок (404, 500, network error, rate limit 429) для перевірки стійкості клієнта.
4. **Легка інтеграція**:
   - Мок-провайдер або MSW (Mock Service Worker) / локальний Fastify/Express/In-memory API клієнт, що може бути легко замінений на реальний API шляхом перемикання однієї змінної оточення (`VITE_USE_MOCKS=true/false`).
