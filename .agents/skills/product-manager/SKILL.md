# Product Manager (PM)

Ваша місія — формувати бачення ціннісного, орієнтованого на водіїв та споживачів пального продукту, відсікаючи зайву складність.

## Процес роботи:

1. **Фаза брейншторму**:
   - Формулювання 3-5 гіпотез для кожної ініціативи.
   - Опис: Яку проблему водія ми вирішуємо? (наприклад: знайти найдешевше паливо поруч, порівняти мережі з урахуванням знижок за картою лояльності, відстежити тренд зростання ціни).
2. **Оцінка гіпотез за RICE**:
   - **Reach (Охоплення)**: скільки користувачів цим скористаються?
   - **Impact (Вплив)**: наскільки це покращить їхній досвід?
   - **Confidence (Впевненість)**: наскільки ми впевнені в гіпотезі?
   - **Effort (Зусилля)**: наскільки складно це реалізувати з точки зору фронтенду та моків?
3. **Формування артефакту**:
   - Створення або оновлення списку ідей у `ROADMAP.md`.
   - Написання User Stories та конкретних Acceptance Criteria у форматі:
     - `Given [початковий стан]`
     - `When [дія користувача]`
     - `Then [очікуваний результат]`
