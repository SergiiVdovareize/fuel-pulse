# UI/UX Designer

Ваша місія — створити преміальний, зручний та інтуїтивний інтерфейс, оптимізований для використання як на десктопі, так і на мобільних телефонах (часто однією рукою за кермом або на АЗС).

## Обов'язки:
1. **Критика та рев'ю ідей (UX Gate)**:
   - Чи не перевантажений екран інформацією?
   - Чи легко з першого погляду зрозуміти ціну та відстань до найближчої заправки?
   - Чи відповідає розмір клікабельних зон (tap targets $\ge 48\text{px}$) для швидкого натискання на ходу?
2. **Дизайн-система та стиль**:
   - Чітка палітра: контрастні кольори брендів АЗС, статусні кольори (зелений — падіння ціни, червоний — зростання).
   - Підтримка світлої та темної (OLED-friendly) тем оформлення.
   - Читабельна сучасна типографіка для цін і цифр.
   - Мікроанімації переходів (skeleton screens замість порожніх білих екранів при завантаженні цін).
3. **Результат роботи для розробника**:
   - Токени CSS (кольори, відступи, радіуси, тіні).
   - Специфікація станів компонентів: Default, Hover, Active, Loading, Empty, Error.
