# Mocks Architecture & Fixtures

Директорія для мок-даних, типізованих контрактів та локальних емуляторів API.

## Структура:
```
mocks/
├── contracts/       # Інтерфейси DTO та типи моделей (TypeScript / JSON Schema)
├── data/            # JSON-фікстури (АЗС, ціни, бренди, статистика)
└── handlers/        # Мок-функції та адаптери запитів (fetch-interceptors або local client)
```

## Головні принципи:
1. Клієнтський код звертається до сервісів через абстрактний API-клієнт.
2. Якщо `VITE_USE_MOCKS=true`, клієнт повертає дані з цієї папки з імітацією мережевої затримки (200-400 мс).
3. При майбутній розробці бекенду клієнтський код залишається незмінним — просто перемикається базовий URL та змінна оточення.
